# mp_12_api · Gestión de Aeropuertos

Mini proyecto Flutter adaptado a **gestión de aeropuertos**.

Todos los ejemplos de este módulo aparecen juntos en una sola pantalla desplazable. Las carpetas internas se mantienen separadas para conservar la organización académica del proyecto.

## Ejecución

```powershell
flutter clean
flutter pub get
flutter run -d chrome
```
