# MP 07 - Layouts aeroportuarios

Mini proyecto Flutter dedicado a practicar los layouts principales mediante ejemplos de gestión de aeropuertos.

Incluye:

- `Container`: tarjeta de información de un aeropuerto.
- `Column`: eventos operacionales.
- `Row` y `Expanded`: estados de aeropuertos.
- `Stack` y `Positioned`: códigos IATA, estado y alertas.
- `Padding`, `Align` y `Wrap`: servicios y datos de vuelos.

## Ejecutar

```powershell
flutter pub get
flutter run -d chrome
```
